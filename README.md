# Учёт расходов

Консольное приложение на Python для учёта личных расходов.

## Возможности
- добавление расхода с проверкой ввода (try/except)
- подсчёт общей суммы
- поиск самой большой траты
- удаление категории
- сохранение и загрузка данных из JSON

## Запуск
python expense_tracker.py

## Стек
Python: функции, циклы, словари, обработка ошибок, работа с файлами
